La méthode de tri par bulles fonctionne en faisant plusieurs passes successives sur la liste, où chaque passage consiste à comparer chaque paire de nombres voisins et à les échanger si nécessaire.

Voici un exemple de code en Python pour la méthode de tri par bulles :

```python
def tri_bulle(liste):
    n = len(liste)
    for i in range(n):
        for j in range(0, n-i-1):
            if liste[j] > liste[j+1]:
                liste[j], liste[j+1] = liste[j+1], liste[j]
    return liste

# Exemple d'utilisation
ma_liste = [64, 34, 25, 12, 22, 11, 90]
print("Liste non triée:", ma_liste)
ma_liste_triee = tri_bulle(ma_liste)
print("Liste triée:", ma_liste_triee)
```
